Sample Content

This is a demo page showcasing the chat widget integration. The bot can answer questions about any website it's embedded on by analyzing the content.

Features

  • Responsive chat widget
  • Real-time AI-powered responses
  • Context-aware answers based on website content
  • Clean and modern UI

How It Works

The chat widget connects to a serverless API deployed on Vercel. The API uses RAG (Retrieval-Augmented Generation) technology to scrape the current website, index its content, and generate relevant responses to user questions.
